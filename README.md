## ⚡ What is Hyper Focus?

Hyper Focus is a **next-gen focus productivity app** with a cyberpunk command-center aesthetic. It's not just a Pomodoro timer — it tracks your session quality, logs every distraction automatically, integrates with Spotify, and gives you a full focus score after every session.

Built for students, developers, and deep work addicts who take their attention seriously.

## 🧠 Features

| Feature | Description |
|--------|-------------|
| 🔐 **Neural Login** | Sign in with email only — no password required |
| 🕐 **Triple-Ring Timer** | Real-time HRS / MIN / SEC rings with custom duration |
| ⚙️ **Configure Timer** | Set exact duration, use quick presets, save your own |
| 📋 **Task Nexus** | Add, queue, activate, and complete tasks across sessions |
| 📡 **Signal Log** | Auto-logs every distraction — tabs, noise, chat, phone, thoughts |
| 🎵 **Spotify Integration** | Launch your focus playlist without leaving the app |
| 🧘 **Wellness Preferences** | Posture checks, hydration reminders, Do Not Disturb mode |
| 🔒 **Focus Lock** | Full-screen mode — no sidebar, no widgets, just the timer |
| 📊 **Session Complete** | Focus score, distraction count, task status, and reflection |
| 🔥 **Streak Tracker** | Tracks your daily focus streak across sessions |
| 🗺️ **Focus Map** | 30-day heatmap of your focus intensity |
| 🗂️ **Session Archive** | History of all past sessions with stats |

## 🚀 Getting Started

### Prerequisites

Make sure you have **Git** installed on your machine.

```bash
git --version
```

### Clone the Repository

```bash
git clone https://github.com/AtharvaK-XD/hyper-focus.git
```

### Navigate into the Project

```bash
cd hyper-focus
```

### Open Locally

Since this is a pure HTML/CSS/JS project — no build step needed. Just open the file:

```bash
# Option 1 — Open directly in browser
open index.html

# Option 2 — Use VS Code Live Server (recommended)
code .
# Then right-click index.html → "Open with Live Server"

# Option 3 — Use Python's built-in server
python -m http.server 3000
# Then visit http://localhost:3000
```
