# Focus Session Board

Neural Noir deep-work productivity dashboard with Focus Lock Mode, task management, distraction logging, and session archive.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React
- canvas-confetti

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (typically `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Features

- Pomodoro-style timer with 25 / 50 / custom presets
- Fullscreen Focus Lock with breach detection
- Task Nexus with drag-to-reorder and status filters
- Signal Log for quick distraction logging
- Session archive with localStorage persistence
- Confetti on zero-distraction sessions
